# Contributing to ReplaceCharacter

Thank you for your interest in contributing! Here is how you can help.

## 🐛 Reporting Bugs

Open an issue on the [Issues tab](../../issues) and include:

- Your operating system and version (e.g., Windows 11, Ubuntu 24.04)
- Steps to reproduce the bug
- What you expected vs. what actually happened
- Any error message shown in the log panel or the terminal
- The pattern (Find / Replace / Regex) you were using when the bug occurred

## 💡 Suggesting Features

Open an issue describing:
- What the feature does
- Why it would be useful
- A rough idea of how it would look in the UI

Popular suggestions for future versions:
- Recursive subfolder processing
- Numbering / sequencing files (e.g., add `001_`, `002_`, …)
- Case conversion (to uppercase, lowercase, title case)
- Add / remove prefix or suffix to all filenames
- Rename preview export to CSV

## 🔧 Pull Requests

1. Click **Fork** at the top of the repository page
2. Make your changes in your fork
3. Test that the rename, undo, redo, and preview all work correctly
4. Test with both regex and plain-text modes, and both case options
5. Open a **Pull Request** back to this repository
6. Describe your changes clearly

### Code Style
- Keep the single-file structure for small changes
- Follow existing type hints and docstring style
- The `RenameEngine` class contains pure logic — keep GUI code out of it

## 🌍 Translations

If you can translate the README into Persian (Farsi), Arabic, Russian, Chinese, or any other language, please contribute a file named `README.fa.md`, `README.ar.md`, etc.
